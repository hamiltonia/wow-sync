# WoW Sync v0.1.0 (pre-release)

An **unsigned Windows x64 preview**. It is a pre-release for testing, not a
finished product. **It does not sync real WoW data yet.**

## What it is

- A single `wow-sync.exe` in a zip. There is no installer and no code signing,
  so Windows SmartScreen will warn that the publisher is unknown. Choose
  "More info", then "Run anyway", only if you downloaded it from this release
  and the SHA-256 in the `.sha256` file matches.
- No macOS build is included. macOS is only compile-checked in CI and has not
  been run.

## The safety gate: synthetic data only

The app only works on an install or provider folder that carries the Q-24
synthetic marker. Without the marker it refuses, so this build will not
enroll your real WoW installation or touch your real add-ons and saved
settings. This is deliberate; real-data enrollment is a later release.

Use it only to try the app on a copy or test folder you created for that
purpose.

## What works (on marker-gated data)

- Tray app and window: setup, sync status, history.
- Sync of add-on code between computers through a shared provider folder, with
  current plus two previous copies kept per add-on.
- Removal that propagates and is recoverable. Uninstall captures the add-on's
  saved settings (within the size cap below) and removes them with the code.
  Restoring a removed add-on reinstalls its code from a local recovery copy or
  the shared folder, brings back the captured settings, and waits while WoW is
  running. If no settings copy from before the removal exists, the add-on
  comes back with its code only and says so. If the recovery data cannot be
  read or does not match the removal record, nothing is installed, and the
  restore request can stay listed as pending.
- Rollback that rejects a bad release for the whole group; offline computers
  cannot bring it back.
- Decisions you can act on (choose, keep, resume, allow again), retire and
  explicit re-enrollment of a computer.
- Settings sync model: consent with an account list, a master, per-add-on
  exceptions, pause/resume and recovery.
- Notices: OS notifications and an update-check notice.
- Diagnostics: a previewed, redacted export that never overwrites an earlier
  one.
- Background memory measured at about 37 MiB (limit 100 MiB) on Windows x64
  in run-004; sync started in about 2.3 s.

## Known gaps

- **No real WoW data** (Q-24 gate above).
- **Settings sync size cap:** a settings file over 32 MiB is skipped for that
  add-on and shown as too large. On uninstall, such a file is left in place:
  it is not removed with the code and is not captured for recovery.
- **Update notice:** the app checks GitHub's "latest release", which ignores
  pre-releases. While only pre-releases exist, About says "No release has been
  published yet." as a plain statement, not a failure, and nothing is logged
  as an error. The app does not notify you about this pre-release or later
  pre-releases, because it never offers a pre-release as an update.
- **Released-version dates:** a release held only by another computer has no
  date, because no shared record carries one.
- **Diagnostics save** goes to your Documents folder (or your home folder if
  there is none) under a time-stamped name and never overwrites an earlier
  export; there is no file picker.
- **Not built:** installer, code signing, telemetry, real-data enrollment,
  macOS runtime, performance budgets beyond the memory and start-time gates.
- The macOS owner run is still open; macOS is compile-checked in CI only.

## Verifying the download

Compare the SHA-256 of `wow-sync-0.1.0-windows-x64.zip` with the value in
`wow-sync-0.1.0-windows-x64.zip.sha256`:

```powershell
Get-FileHash .\wow-sync-0.1.0-windows-x64.zip -Algorithm SHA256
```
