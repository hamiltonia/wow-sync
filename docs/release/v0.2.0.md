# WoW Sync v0.2.0 (pre-release)

An **unsigned Windows x64 preview**. It is a pre-release for testing, not a
finished product.

## Real installs work without opt-in

v0.1.0 refused any install without the Q-24 synthetic marker. v0.2.0 no longer
needs it: the app works on your real `Interface\AddOns` and `WTF` folders.

**Back up your `Interface\AddOns` and `WTF` folders first.** That is advice,
not a gate; the app will not ask for proof that you did.

## The Forever toc rule

For a Forever install the app picks the add-on's `.toc` file in this order:
Forever and Camelot, then Mainline, then plain. The source is public
documentation. The owner's in-client check of this rule is pending.

## Test mode

A folder that carries the `.wowsync-synthetic` marker is treated as a test-mode
install. Use it to try the app on a copy without touching real data. The
marker is optional for real installs.

## Still missing

- No installer, no code signing and no macOS binary. Windows SmartScreen will
  warn that the publisher is unknown, as in 0.1.0: choose "More info", then
  "Run anyway", only if you downloaded it from this release and the SHA-256 in
  the `.sha256` file matches.
- The GUI items recorded as BLOCKED in run-005 are still not verified.
- The 0.1.0 known gaps that are not listed as fixed here still apply, including
  the 32 MiB settings size cap and the update notice that ignores
  pre-releases.

## Verifying the download

Compare the SHA-256 of `wow-sync-0.2.0-windows-x64.zip` with the value in
`wow-sync-0.2.0-windows-x64.zip.sha256`:

```powershell
Get-FileHash .\wow-sync-0.2.0-windows-x64.zip -Algorithm SHA256
```
