# WoW Sync v0.2.0 (pre-release)

An **unsigned Windows x64 preview**. It is a pre-release for testing, not a
finished product.

## Real installs work without opt-in

v0.1.0 refused any install without the Q-24 synthetic marker. v0.2.0 no longer
needs it: the app works on your real `Interface\AddOns` and `WTF` folders.

**Back up your `Interface\AddOns` and `WTF` folders first.** That is advice,
not a gate; the app will not ask for proof that you did.

## First-run safety

The first run never deletes anything without a recovery point.

- An older add-on that the first run replaces is kept as a recovery point. To
  get it back, use Rollback. Rollback is not a local undo: it rejects the
  newer release for the whole group and returns every computer to the
  previous version.
- If the group already removed an add-on that you have on your computer, your
  copy is kept, and the add-on stays listed as removed.
- Add-ons with the same name and the same version number but different
  content are left untouched on both sides. An add-on with the same name and
  a newer version is replaced, with a recovery point.
- Add-ons that only you have are kept and published.

## The Forever toc rule

For a Forever install the app picks the add-on's `.toc` file in this order:
`_Forever` or `_Camelot`, then `_Mainline`, then plain. The order comes from
the warcraft.wiki.gg "TOC format" page and has not yet been checked in the
client (Q-3).

Existing installs enrolled under the old plain-toc rule (`validated-plain/1`)
are asked to reconfirm once under the new Forever rule (`profile:wowf/2`).
Nothing is lost.

## Test mode

Test mode is a toggle in Settings and is off by default. While it is on, only
folders that carry the `.wowsync-synthetic` test marker sync; unmarked installs
are stopped with a plain explanation, and nothing is un-enrolled or changed.
Turning it off resumes them. A marker folder does not turn test mode on by
itself, and the marker is not needed for real installs.

## Still missing

- No installer, no code signing and no macOS binary. Windows SmartScreen will
  warn that the publisher is unknown, as in 0.1.0: choose "More info", then
  "Run anyway", only if you downloaded it from this release and the SHA-256 in
  the `.sha256` file matches.
- The GUI items recorded as BLOCKED in run-005 are still not verified.
- The 0.1.0 known gaps that are not listed as fixed here still apply, including
  the 32 MiB settings size cap and the update notice that ignores
  pre-releases.

## Verifying the download

Compare the SHA-256 of `wow-sync-0.2.0-windows-x64.zip` with the value in
`wow-sync-0.2.0-windows-x64.zip.sha256`:

```powershell
Get-FileHash .\wow-sync-0.2.0-windows-x64.zip -Algorithm SHA256
```
