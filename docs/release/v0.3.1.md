# WoW Sync v0.3.1 (pre-release)

An **unsigned Windows x64 preview**. Fixes the setup hang seen on a second PC.

## Fixed

- Choosing a game folder in setup step 3 no longer freezes the app. The check
  of your add-ons now runs in the background with a visible file count and a
  **Cancel check** button. It only reads; nothing is written.
- Tray **Quit** now exits within a few seconds even while a check is running.
  A sync step that is already writing still finishes safely first.
- A check result is shown only for the folder it was made for.
- Setup selects a usable install (one with `.flavor.info`) first; refused
  folders such as `_classic_beta_` stay listed but are no longer the default.
- The log records `inspect start`, `inspect done ... in N ms`,
  `inspect cancelled` and `tray: <item>`.
