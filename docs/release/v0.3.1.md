# WoW Sync v0.3.1 (pre-release)

An **unsigned Windows x64 preview**. Fixes the setup hang seen on a second PC.

## Fixed

- Choosing a game folder in setup step 3 no longer freezes the app. The check
  of your add-ons now runs in the background with a visible file count and a
  **Cancel check** button. It only reads; nothing is written.
- Tray **Quit** abandons any read-only add-on scan (setup check, status,
  sync scan, enrollment check) at the next file, so it exits within a few
  seconds. Only a write already in progress (applying files or publishing)
  finishes first, whole, and a cycle that has written files still publishes.
  A scan cut short by Quit changes nothing.
- Each sync pass scans the add-ons about 4 times instead of about 12.
- A re-check of a row shows progress and Cancel and keeps Next disabled until
  it ends; a check that crashes ends as an error instead of staying "checking".
- A check result is shown only for the folder it was made for.
- Setup selects a usable install (one with `.flavor.info`) first; refused
  folders such as `_classic_beta_` stay listed but are no longer the default.
- The log records `inspect start`, `inspect done ... in N ms`,
  `inspect cancelled` and `tray: <item>`.
- Quitting from the tray during setup now exits as soon as any write in progress finishes (it previously could open a hidden prompt). Choosing a game folder selects its usable install first.
- A full first check of a large install (31k files, 3.2 GB) can take about 2 minutes on a cold disk; progress and Cancel are shown.
