# WoW Sync v0.3.3 (pre-release)

An **unsigned Windows x64 preview**. Update every computer in the group.

## New

- **Activity shows what changed.** Each pass is one entry, newest first, for
  example "15 add-ons updated from RYZENFISH (+1.8 GB)". Open it to see each
  add-on: old → new version, files added (+), changed (~) and removed (−), the
  size change and the reason ("you chose RYZENFISH's copy", "newer release",
  "removed on RYZENFISH", "settings master"). Open a row to list the changed
  files, relative to the add-on folder, capped with "and N more". Older plain
  lines still appear.
- **Each add-on's page has "Recent changes".**
- **Live progress.** While a pass works, the headline and the tray tooltip say
  what it is doing, for example "Installing 15 add-ons from RYZENFISH: 1.2 of
  1.8 GB (SpokenQuestsAudioShared)", "Removing Atlas" or "Publishing changes:
  3 of 7". Before a large install the line under the headline says what is
  incoming. The display updates about twice a second at most. A routine check
  that lasts under about a second and a half is not shown at all.
- **A waiting decision stays the headline.** Routine checks (scanning,
  deciding, publishing) never replace "Waiting for your decision"; their
  progress shows as a quiet line under it instead. The headline changes only
  when an install or removal actually starts, and a decision that was
  satisfied no longer counts as waiting.
- **After a pass that changed something**, the headline says for about 20
  seconds, for example, "Updated 15 add-ons from RYZENFISH — see Activity".
  Later routine checks do not clear it; starting real work does.
- **The log is quiet when nothing happens.** A pass that does work logs why it
  started, each phase, each add-on applied or removed (name, source computer,
  versions, file counts, bytes, ms) and a pass summary. A routine check that
  finds nothing logs nothing, or one "slow check" line if it took two seconds
  or more. No paths, account or character names, or file contents.

## Known limits

- The history and progress come from the sync service; older entries written
  before this version show as plain lines.
- The "Checking files: X of Y" counter can include work from earlier checks, so
  treat the numbers as rough.
- During a long install the named add-on and the byte count can run slightly
  behind the work. When several computers contribute to one apply, the
  wording follows the computer currently being installed from.
- A local uninstall and an interrupted apply finished after a crash may not
  leave an Activity entry.
- Per-file counts on "Shared N new items from this computer" are a best
  effort.
