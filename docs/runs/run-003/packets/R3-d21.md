## Goals

1. **Remove the Interface/build compatibility gating (Q-21 by D-21).**
   - A candidate from a computer on a different or unknown client build is
     treated the same as one from the same build.
   - A malformed or missing `## Interface:` never withholds a candidate.
   - **The variant boundary stays exactly as is.** So do the matching
     account/character boundaries and every ordering, ambiguity and identity
     rule. Never-match variant tests must still pass.
   - Remove the code paths that become dead, such as `interface_supported`
     and `same_known_build`. If something is still used for display, keep
     only the parsing.
   - Update or remove the tests and required cases that asserted the
     gating. Replace them with tests that assert the new behaviour:
     - a different build with a different or malformed Interface still
       syncs;
     - a different variant still never syncs.
   - A-38 negative control: re-introduce a build-based hold and show that a
     named new test fails with exit 101, then restore.
2. **Update the design docs to match D-21.**
   - `domain.md` and `tests.md`: the Q-21 rule.
   - `questions.md`: mark Q-21 and Q-26 to Q-53 per D-21, with each answer
     and "owner, D-21".
     - Q-42 is rejected.
     - Q-26 is hide by default plus a settings option to quit on close.
     - Q-45: WoW keeps the saved variables.
   - `removal.md`: a short top note listing what D-21 changes:
     - removal wins over a concurrent offline update;
     - no mass-removal confirmation;
     - a joining computer simply removes the addon.
     - R3D-13 must be re-reviewed against D-21.

     Do not redesign the removal model itself.
3. **Delete the obsolete spikes** `spikes/gpui`, `spikes/mem` and
   `spikes/a11y`, including their lockfiles. This closes Dependabot alerts
   2 to 4.
   - Keep every other spike.
   - Fix any reference that breaks: xtask, CI, `deny.toml`, docs links. If a
     needed fix is in a path you don't own (`xtask/`, `.github/`,
     `deny.toml`, other docs), you may make it. List each such file in your
     evidence.
   - Docs that cite the spikes' results stay, because the results live in
     the run evidence.
